# javascript-calculator-precourse

- [ O ] 빈 문자열 입력 시 0이 출력 되어야 한다.

- [ O ] 기본 구분자(쉼표, 콜론)을 기준으로 분리한 각 숫자의 합을 반환해야 한다.

- [ O ] "//" 와 "\n" 사이에 위치하는 문자는 커스텀 구분자로 지정하고 사용도 가능 해야 한다. ex : //;\n1;2;3 (커스텀 구분자 ; 이고, 결과 값은 6임!)

- [ O ] 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메세지와 함께 Error을 발생시킨 후 애플리케이션이 종료되어야 한다.

- [ O ] 출력은 "결과 : ${결과값}" 형태로 덧셈 결과가 출력되어야 한다.
